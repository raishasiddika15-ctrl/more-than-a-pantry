# Team Workflow

## Weekly Standup Questions

Each teammate should answer:

1. What did you complete?
2. What are you working on next?
3. What is blocking you?
4. What do you need from the client or team?

## Suggested Roles

### Technical Manager
- Owns documentation
- Coordinates engineers/designers
- Tracks blockers
- Summarizes client feedback
- Keeps scope realistic

### Product Manager
- Helps prioritize client needs
- Clarifies user stories
- Supports timeline and presentation

### Designer
- Creates visual direction, wireframes, accessibility notes
- Works with content and engineering

### Engineer
- Builds pages/components
- Handles forms/integrations
- Tests responsiveness and functionality
